Falabella Financiero · Platform leadership

Balancing critical operations with roadmap commitments

As a platform manager at Falabella Financiero, I led teams supporting payments, insurance, and digital banking. The same people who kept those services running also had to make time to improve them.

The decision
I worked with four tech leads to bring operational workload, platform ownership, and planned work into one view, so we could weigh roadmap commitments against the capacity needed to run the platforms.
What changed
When a new priority came in, tech leads could show stakeholders where their capacity was going and which commitments would need to move. That gave teams a shared basis for making trade-offs.

Personal project · Concept design

Reviewing what software agents produce

I’m designing a workflow that connects product requirements, architecture decisions, and test evidence so a reviewer can decide whether an AI-assisted change is ready to move forward.

See an illustrative review
Requirement
In a fictional reporting tool, finance users can export reports. Other users have read-only access.
Architecture decision
The export endpoint enforces access on the server. The agent can propose an implementation and tests for review.
Evidence
The submitted tests show that a finance user can export a report. The test that checks whether a read-only user is blocked is missing.
Review decision
Return the change with a request for the missing test. A human reviewer makes the approval decision once there is evidence for both paths.
