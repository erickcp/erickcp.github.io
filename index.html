Falabella Financiero · Leadership case

Making team capacity visible

I worked with four tech leads to make operational workload, platform ownership, and roadmap capacity visible across payments, insurance, and digital banking.

Read the case
What was at stake
Teams had to keep critical services running while making time to improve them.
What I changed
We put operational workload, ownership, and planned work into the same operating model so leads could bring shared evidence into prioritization discussions.
What it enabled
Leads and stakeholders could discuss capacity constraints and delivery priorities using the same information.

Personal project · Concept design

Reviewing what software agents produce

I’m exploring how product requirements, architecture decisions, and quality checks can give teams a clear way to review work produced with AI.

See an illustrative example
Requirement
Export a report. The product spec defines who can export it and which fields belong in the file.
Evidence
The review checks that a permitted user can export the report and that an unauthorized user cannot.
Decision
If the permission test is missing, send the work back with the specific gap. A reviewer decides when the evidence is sufficient.
